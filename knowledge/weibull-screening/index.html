Weibull / Screening

β·η fitting보다 mechanism continuity, mixed population, low-percentile stability를 우선합니다.

ContentsConsensusBoundaryNext DOE

Current consensus

β 변화와 Weibull curvature는 단순 통계 noise가 아니라 competing population 또는 mechanism crossover의 신호일 수 있습니다. synthetic/predicted samples를 physical failure sample과 동일 취급해서는 안 됩니다.

Critical boundary

Outlier screening은 실제 extrinsic early-failure population을 지울 위험이 있습니다. statistical deletion 전에 FA/mechanism evidence가 필요합니다.

Recommended discriminating DOE

sample injection/leave-one-out로 β, η, acceleration slope, 1-ppm quantile, confidence interval stability를 비교하고 physical fail signatures와 결합합니다.

W43 Evidence Update · 19 Oct 2026

Consensus / Open Questions / Contradictions / Validated Models / Domain Boundaries / DOE

W43의 row/column/peripheral intermittent fault와 cell TDDB를 하나의 Weibull population으로 합치지 않는다. 검출확률은 반복 관측의 상관성과 fault activation probability를 고려한다.

English. Do not pool intermittent row/column/peripheral faults with cell TDDB in one Weibull population. Detection probability depends on observation correlation and fault activation probability.

Contradiction / Critical Boundary: Contradiction: a passing single-shot screen does not imply low intrinsic failure hazard; false negatives can dominate.

Recommended DOE: DOE: independent repeats × state/clock/temperature × physical fault classification; track miss rate, conditional β and failure-site identity.

Validated Models: Source-specific numeric model not established from public abstract; generic equations are Engineering Inference, EXTRAPOLATION ONLY beyond validated conditions.

Key Sources / Provenance: W43 paper 1–5; compare W37–W39. W43 review is pending publication gate.
