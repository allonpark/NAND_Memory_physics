# W41 감사 자료 (외부 감사용)

`reports/2026/w41/index.html`이 거친 근거와 검증의 기록입니다.

| 경로 | 내용 |
|---|---|
| `sources.yaml`, `rejected.md` | 출처 5건(DOI/arXiv, 날짜, 접근 수준, 신규/archive-gap)과 탈락 후보. manifest의 알려진 오류는 파일 머리말의 ERRATA에 적었습니다 |
| `fulltext_notes/` | 본문을 읽은 항목의 추출 노트(요약형 추출 도구를 쓴 경우 일부 값은 두 번째 독립 읽기로 확인) |
| `review/review.md`, `review/recheck.md` | 수정된 본문에 대한 독립 검수(2차)와 그 수정에 대한 집중 재검수 |
| `fixlog.md` | 수정 기록(1차, 2차, 조정자 3차) |
| `notes/` | 작성자의 SOURCE_REPORTED, UNKNOWN 목록과 약점 |
| `scripts/` | SymPy 검산 스크립트와 실행 출력, 점검 스크립트 |

한계:
- **첫 번째 독립 검수의 보고서 원문은 임시 폴더 소실로 잃었습니다.** 그 검수의 결론(확정 blocker 0건, 엄격 기준 3건과 그 밖의 major/minor)은 수정 기록에 요약으로만 남아 있고, 이 폴더의 검수 문서는 수정 후 본문에 대한 두 번째 검수와 재검수입니다.
- 작성 중간 파일은 에이전트 기록에서 복구했고, Bash로 한 수정은 복구되지 않아 일부가 다를 수 있습니다. 이 때문에 최종 본문은 위 검수를 거친 상태 기준입니다.
- 항목 5는 초록만 읽었습니다(출판사 페이지 403, 우회하지 않음). 그림은 읽지 못했습니다.
- 재검수 이후의 마지막 minor 수정은 기계 점검만 받았습니다.
- `scripts/`의 로컬 경로는 `<local-path>`로 치환되어 그대로 실행되지는 않습니다.
