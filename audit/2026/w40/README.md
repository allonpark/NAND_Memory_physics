# W40 감사 자료 (외부 감사용)

이 폴더는 2026-W40 보고서(`reports/2026/w40/index.html`)가 어떤 근거와 검증을 거쳤는지 따라갈 수 있게 한 기록입니다.

| 경로 | 내용 |
|---|---|
| `sources.yaml` | 출처 5건(DOI, 날짜, 접근 수준, 신규/archive-gap, 초록 기준 사실). 5건 모두 `abstract_only` |
| `sources_crossref/` | 검수자가 Crossref API에서 다시 받은 원본 JSON(초록 포함) |
| `review.md` | 독립 검수 1차 결과(지적 사항 번호, 심각도, 위치, 수정안) |
| `fixlog.md` | 1차 지적 사항별 적용 여부 |
| `recheck.md` | 수정 후 독립 재검수 결과 |
| `final_pass.md` | 마지막 수정 패스(문체 통일 포함)의 기계 점검 결과 |
| `notes/` | 작성자의 SOURCE_REPORTED 목록, UNKNOWN 목록, 약점 |
| `scripts/` | sympy 검산 스크립트와 실행 출력 |

한계:
- 본문은 읽지 않았습니다(초록 기준). 출판사 페이지는 접근이 막혀 확인하지 못했습니다.
- 마지막 수정 패스의 사소한 수정은 독립 재검수 없이 기계 점검만 받았습니다.
- `scripts/` 안의 로컬 경로는 `<local-path>`로 치환되어 그대로 실행되지는 않습니다. 식과 출력은 그대로 읽을 수 있습니다.
- `fixlog.md` 등에 내부 처리 서술이 남아 있습니다.
