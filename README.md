# NAND Memory Physics

A web-first archive of weekly VNAND and high-voltage device reliability briefs.

## Site structure

- `index.html` - landing page and weekly archive
- `reports/YYYY/wNN/` - detailed weekly web reports
- `downloads/YYYY/` - downloadable PDF reports
- `figures/YYYY/wNN/` - source-anchored scientific redraws / qualitative schematics
- `assets/` - shared styles

## Publication rules

Each weekly report separates source-reported findings from engineering inference and includes physical structure, causal chain, equations with interpretation, parameter/scaling analysis, competing mechanisms, VNAND/HV material translation, validation signatures, failure/tail analysis, DOE, counterarguments and critical boundaries.

Figures must pass source, physics, geometry, graph-integrity, layout and cross-consistency QC. Numeric plots are not reconstructed unless source data are available; qualitative figures are explicitly labeled.
