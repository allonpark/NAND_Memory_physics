# W43 감사 자료 (외부 감사용)

`reports/2026/w43/index.html`이 거친 근거와 검증의 기록입니다.

| 경로 | 내용 |
|---|---|
| `sources.yaml`, `rejected.md` | 출처 5건(DOI, 날짜, 접근 수준, 신규/archive-gap, 읽은 사실의 위치)과 탈락 후보 사유 |
| `sources_crossref/` | 검수자가 다시 받은 Crossref 원본 JSON |
| `fulltext_notes/` | 본문을 읽은 3건(항목 3~5)의 추출 노트. 요약형 추출 도구로 읽어 그림은 읽지 못했고 일부 수식은 깨졌습니다 |
| `review.md`, `recheck.md`, `fixlog.md` | 독립 검수 1차, 수정 후 재검수, 지적 사항별 적용 기록 |
| `notes/` | 작성자의 SOURCE_REPORTED, UNKNOWN 목록과 약점 |
| `scripts/` | sympy 검산과 점검 스크립트, 실행 출력 |

한계:
- 항목 1은 유료, 항목 2는 접근 거부(403)라 초록만 읽었습니다. 접근 제한은 우회하지 않았습니다.
- 본문 3건은 요약 도구가 본문 일부(약 100,000자 이후)를 자르는 경우가 있어, 중요한 조건은 오프셋을 달리해 다시 읽어 확인했습니다. 그림 내용은 읽지 못했습니다.
- 재검수 이후 반영한 사소한 수정(minor 5건)은 독립 재검수 없이 기계 점검만 받았습니다.
- `scripts/`의 로컬 경로는 치환되어 그대로 실행되지는 않습니다.
