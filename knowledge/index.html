Why this layer exists

Weekly reports answer “what appeared this week?”. This layer answers “what do we currently believe, what is still contradictory, and what experiment would change our mind?”.

The archive is evidence history. The mechanism map is the current engineering state of knowledge.

Update rule

새 논문은 먼저 Claim-Evidence Model Card로 구조화하고, VALID RANGE와 failure criterion을 확인합니다. 이후 기존 mechanism page의 Consensus / Contradictions / Domain Boundaries / Open Questions를 업데이트합니다. 범위 밖 적용은 EXTRAPOLATION ONLY로 표시합니다.
